## The problem

Condominium operations connect people with different responsibilities: residents, staff, guards, and administrators. Announcements, amenity bookings, maintenance requests, and entry logs need a shared home, with views appropriate to each user.

CondoLink is my capstone project addressing these workflows through a responsive web application.

## My contribution

I worked as the **full-stack developer and project lead**. My responsibilities covered planning, feature development, testing, debugging, and delivery.

- Built front-end dashboards with **React**, **TypeScript**, and **Tailwind CSS**.
- Developed **PHP** application logic for system workflows.
- Connected **MySQL** tables to support dynamic, user-specific features.
- Implemented role-based access and managed project development.

## How the system fits together

The React interface presents the dashboards and forms. PHP handles application workflows, with MySQL providing persistent data for the management features.

1. **Interface:** residents and staff interact with responsive dashboards.
2. **Application:** PHP connects user actions to the relevant workflow.
3. **Data:** MySQL stores the information used by the system.

The key challenge is coordinating these layers while keeping different users’ tasks understandable.

## Core workflows

- **Residents:** announcements, amenity bookings, and maintenance requests.
- **Staff and administrators:** management dashboards, reports, and request tracking.
- **Guards:** entry logs and relevant operational views.
