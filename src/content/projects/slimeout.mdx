## The idea

SLIMEOUT is a lightweight one-button maze game built in **Unity**. Players guide a slime through an endless maze, navigating obstacles with simple controls.

The project focuses on a small gameplay loop: input, movement, obstacles, and feedback.

## My work

I developed the game using Unity and programmed gameplay logic in **C#**, with mechanics focused on simple input and replayability.

- One-button control scheme.
- Maze-style movement and obstacles.
- Reflexes and fast decision-making.
- Responsive feedback as the player moves through the game.

## Why simple input matters

A limited control scheme keeps attention on timing and decisions. It also makes game feel important: movement and feedback need to be understandable without a large set of instructions.

This project let me practice building a small interactive system rather than a conventional web interface.

## What I learned

I gained experience with gameplay logic, player feedback, and the relationship between input and responsiveness. These ideas also apply to interface development: a clear action should produce an understandable response.
