## The brief

Create a single place to introduce my IT support background, present development projects, and make my résumé and contact information easy to find.

This is an **earlier portfolio built with React and Vite**, separate from the Astro website you are reading.

## What I built

- A responsive single-page layout for desktop and mobile.
- Sections for projects, skills, experience, and contact information.
- Project highlights for CondoLink and SLIMEOUT.
- Links to my résumé, GitHub, and LinkedIn.
- A static deployment on GitHub Pages.

## Technical structure

**React 19** provides the interface components, **Vite** handles the development and production build, and **Tailwind CSS 4** provides styling.

The site is a static frontend. Contact links give visitors a direct next step without requiring an account or a backend form.

## What I learned

The project helped me practice organizing professional information, building responsive interfaces, and deploying a frontend with a GitHub Pages base path.

It also provided a starting point for thinking more carefully about portfolio hierarchy: show the work, explain the contribution, and make contact straightforward.

## What changed in this portfolio

The current Astro site builds page content to static HTML, gives projects their own MDX case studies, and links technical skills to examples. It adds an HTML résumé, theme preferences, accessible project filters, and a clearly labeled sample workflow.

The earlier site remains linked as a historical project. Its content may differ from my current résumé.
